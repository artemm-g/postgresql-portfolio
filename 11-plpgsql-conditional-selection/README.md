# 11. Условный выбор записи в PL/pgSQL

**Тема:** `DO`-блок, выбор «лучшей» записи по критерию (`IF` + `ORDER BY` + `LIMIT 1`), фиксация выбора через `INSERT`, `RAISE NOTICE`.

## Задание
Два варианта:
1. Бронирование самого дешёвого свободного номера типа «Стандарт» на конкретную дату (`hotel_booking.sql`).
2. Продажа самого младшего из ещё не проданных котов (`pet_shop.sql`).

## Файлы
- `hotel_booking.sql` — вариант 1.
- `pet_shop.sql` — вариант 2.

## Что в решении
Оба файла устроены одинаково:
1. Первый `DO`-блок создаёт структуру и наполняет данными.
2. Второй `DO`-блок считает подходящие записи. Если их больше нуля, выбирает лучшую по критерию (цена или возраст) среди свободных и фиксирует выбор в таблице `booking` или `sale`.
3. Если подходящих записей нет, выводится сообщение об этом.

Важные детали:
- `SELECT name, id_pet INTO ...` — число столбцов в `SELECT` совпадает с числом переменных в `INTO`.
- Выбор фиксируется `INSERT` в таблицу `sale`.
- Запрос выбора исключает уже проданных котов: `NOT IN (SELECT id_pet FROM sale)`.
