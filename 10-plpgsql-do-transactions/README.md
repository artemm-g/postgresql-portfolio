# 10. DO-блок, ENUM, массивы и транзакция

**Тема:** анонимные блоки `DO`, `ENUM`, массивы, `RETURNING`, `RAISE NOTICE` и `RAISE EXCEPTION`.
**Данные:** интернет-магазин обуви.

## Задание
Оформить покупку одним блоком: создать таблицы, наполнить их, проверить наличие товара на складе, посчитать сумму чека и списать товар. Если товара не хватает, операция должна отмениться.

## Файлы
- `shoe_store_checkout.sql` — единый `DO`-блок: создание, наполнение и оформление чека.

## Что в решении
- Секция `DECLARE` с переменными разных типов.
- `CREATE TYPE ... AS ENUM` для сезона и пола.
- Массивы (`INT[]`, `TEXT[]`) как тип столбца и `ARRAY[...]` при `INSERT`.
- `INSERT ... RETURNING ... INTO` для получения сгенерированных `id` без отдельного `SELECT`.
- `IF` и `RAISE EXCEPTION` для проверки остатка до списания.
- `RAISE NOTICE` для вывода хода выполнения.
- Весь блок выполняется как одна транзакция: при ошибке все изменения откатываются.

## Особенности
Сумма чека хранится в `DECIMAL(10,2)`, а не в `INT`, чтобы не терять копейки.

## Статус
Проверено на реальной БД: сумма чека 2101.00, количество товаров 5.
