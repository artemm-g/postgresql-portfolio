# 06. JOIN и UNION

**Тема:** неявное соединение, `INNER`, `LEFT`, `RIGHT`, `FULL JOIN`, `UNION`.

## Задание
Задачи 1–4: написать запросы к каталогу компьютерной техники (товары, ПК, ноутбуки, принтеры). Задачи 5–6: использовать связи «многие ко многим» через связующие таблицы и объединять выборки через `UNION`.

## Файлы
- `product_pc_laptop_printer_schema.sql` — создание и заполнение таблиц `product`, `pc`, `laptop`, `printer`.
- `queries_tasks_1_4.sql` — решения задач 1–4.
- `tasks_5_6_books_authors_db.sql` — решения задач 5–6 (книги, авторы, издательства, заказы).

## Что в решении
- Неявное соединение через запятую в `FROM` и условие в `WHERE`.
- `INNER JOIN`, в том числе через `USING`.
- `LEFT`, `RIGHT`, `FULL JOIN`, в том числе цепочкой из 2–4 таблиц.
- `UNION` для объединения выборок с одинаковой структурой.
- Агрегаты (`AVG`, `COUNT`, `SUM`) поверх `JOIN`.
- Работа со связующими таблицами `category_has_good` и `sale_has_good`.

## Статус
- `queries_tasks_1_4.sql` — проверено на реальной БД.
- `tasks_5_6_books_authors_db.sql` — скрипт создания таблиц в папке отсутствует, поэтому запустить этот файл с нуля нельзя. Файл оставлен как пример синтаксиса.
