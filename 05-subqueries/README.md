# 05. Подзапросы

**Тема:** скалярные подзапросы, подзапросы в `WHERE`, `IN`, `ANY`, `ALL`, многостолбцовые подзапросы.
**Данные:** музыкальный магазин (`musicstore`); для задачи 5 — прокат автомобилей из папки 02.

## Задание
Задачи 1–4: найти записи, которые сравниваются с результатом другого запроса (максимум, минимум, среднее по группам). Задача 5: решить одну и ту же выборку через `IN`, `ANY`, `ALL` и многостолбцовое сравнение.

## Файлы
- `musicstore_schema.sql` — создание таблицы и заполнение данными.
- `queries.sql` — решения задач 1–4.
- `task5_in_any_all_multicolumn.sql` — решения задачи 5 на базе проката из папки 02.

## Что в решении
- Скалярный подзапрос, который возвращает одно значение и используется как порог в `WHERE`.
- Вложенный подзапрос: сначала `GROUP BY` внутри подзапроса, затем `MIN`/`MAX` по результату.
- Подзапрос как вычисляемое значение прямо в `SELECT`.
