# 03. Функции PostgreSQL

**Тема:** функции на SQL и PL/pgSQL, вызов функций в запросах.

## Задание
Написать функции: одну с переменным числом аргументов, одну с одним параметром (расчёт НДС) и одну с условной логикой. Показать их вызов внутри `SELECT`.

## Файлы
- `tutu_schema.sql` — база `tutu`, таблица `products` и тестовые данные.
- `basic_functions.sql` — функции на SQL и PL/pgSQL и примеры их вызова.

## Что в решении
- Функция на SQL с переменным числом аргументов (`VARIADIC` и `UNNEST`).
- Функция на SQL с одним параметром: расчёт НДС.
- Функция на PL/pgSQL с `IF/ELSE`, `DECLARE` и `RETURN`.
- Вызов функций в `SELECT`, в том числе как вычисляемого поля.
