# 09. Представления (VIEW)

**Тема:** `CREATE VIEW`, представления как способ упростить повторяющиеся запросы и скрыть `JOIN`.
**Данные:** музыкальный магазин (в духе Chinook): клиенты, сотрудники, продажи, исполнители, альбомы, треки, жанры, плейлисты.

## Задание
Создать 11 представлений по заданию. Часть из них решает одну задачу разными способами: подзапросом, `JOIN` и через `EXCEPT`.

## Файлы
- `views.sql` — 11 представлений.

## Что в решении
- Простые представления на одной таблице с `WHERE` и `LIKE`.
- Представления с вычисляемыми полями: перевод байтов в мегабайты.
- Работа с датами: `EXTRACT`, `AGE`, `DATE_PART`.
- Одна задача, три способа: подзапрос, `JOIN`, `EXCEPT`.
- Представления с агрегатами и `GROUP BY` / `HAVING`.
- В расчёте размера используется деление на `1024.0`, чтобы не терять дробную часть.
