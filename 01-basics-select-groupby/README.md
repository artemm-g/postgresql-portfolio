# 01. Базовые SELECT, GROUP BY и HAVING

**Тема:** агрегатные функции, группировка, фильтрация групп.
**Данные:** стоматология (`dentistry`) и чеки (`receipts`).

## Задание
Написать запросы, которые считают показатели по группам: суммы, средние, максимумы, количество уникальных значений. Отдельно нужно отфильтровать группы через `HAVING` и отсортировать результат.

## Файлы
- `dentistry_schema.sql` — создание таблицы `dentistry`.
- `dentistry_queries.sql` — задания 1–4 на таблице `dentistry`. Вставка новых записей входит в задание 4. Исходные строки для заданий 1–3 в папке не включены.
- `receipts_schema.sql` — создание таблицы `receipts` и исходные данные.
- `receipts_queries.sql` — задания 1–5 на таблице чеков: добавление `receipt_id` и `discount`, запросы.

## Что в решении
- `SUM`, `MAX`, `MIN`, `AVG`, `COUNT`, `COUNT(DISTINCT ...)`.
- Группировка по одному полю через `GROUP BY`.
- Фильтрация групп через `HAVING`.
- `ORDER BY` и `LIMIT` поверх агрегатов.
- Вычисляемые поля с псевдонимами в кавычках.

## Статус
- `dentistry_queries.sql` — проверено на реальной БД, результаты сверены с выводом psql.
- `receipts_queries.sql` — на реальной БД не прогонялось. Задачи 4 и 13 формулируются так, что допускают два прочтения; в решении выбран один из вариантов.
