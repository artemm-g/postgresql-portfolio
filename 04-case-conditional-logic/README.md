# 04. CASE, условная логика и Python

**Тема:** оператор `CASE`, CTE, `CREATE TABLE AS`, подключение к PostgreSQL из Python.
**Данные:** автосалон (`car_dealer_7`).

## Задание
Посчитать скидки по объёму продаж: скидка зависит от количества проданных машин и задаётся порогами. Нужно вывести отчёты по моделям и маркам, а также скопировать таблицу с новым вычисляемым столбцом. Те же запросы выполняются из Python через `psycopg2`.

## Файлы
- `car_dealer_schema.sql` — создание таблицы `car_dealer_7`, заполнение и добавление столбца `discount`.
- `queries.sql` — три SQL-запроса с `CASE`.
- `task1_full_discount_report.py` — подробный отчёт по скидкам (запрос из Python).
- `task2_brand_summary_report.py` — сводка по маркам с CTE (запрос из Python).
- `task3_copy_table_with_custom_column.py` — копирование таблицы через `CREATE TABLE AS` и обновление нового столбца.

## Что в решении
- `CASE WHEN ... THEN ... ELSE` для расчёта скидки по порогам.
- Вложенный `CASE` внутри арифметических выражений.
- CTE (`WITH`) для предварительной агрегации перед расчётом.
- `CREATE TABLE ... AS SELECT` для копирования таблицы.
- Подключение к PostgreSQL и выполнение запросов из Python. Параметры подключения берутся из `.env` (шаблон — `.env.example`).

## Запуск Python-скриптов
1. Скопировать `.env.example` в `.env` и заполнить свои данные.
2. Установить зависимости: `pip install psycopg2-binary python-dotenv`.
3. Выполнить `car_dealer_schema.sql`, затем запустить скрипты.
