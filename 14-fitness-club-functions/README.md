# 14. Функции для фитнес-клуба

**Тема:** функции с `RETURNS TABLE`, `OUT`-параметрами и `RECORD`, работа с датами, агрегация внутри функций.
**Данные:** фитнес-клуб (клубы, участники, тренировки, посещения, подписки, персональные тренировки).

## Задание
Десять функций по трём блокам:
- 1.x: расчёты по тренировкам (например, сожжённые калории по длительности).
- 2.x: отчёты по участникам (самый активный участник за месяц, статистика за месяц).
- 3.x: отчёты по клубу (истекающие подписки, полный отчёт по клубу, топ по калориям).

## Файлы
- `functions.sql` — все 10 функций с примерами вызова.

## Что в решении
- Скалярные функции с `RETURNS INT`/`DECIMAL` и модификатором `STRICT` (если любой аргумент `NULL`, функция сразу возвращает `NULL`).
- Функции с несколькими `OUT`-параметрами вместо `RETURNS TABLE` (`get_most_popular`, `most_popular_training`).
- Функция, возвращающая `RECORD`: при вызове нужно указать список столбцов через `AS (...)`.
- `RETURNS TABLE` с `RETURN QUERY` для функций, которые возвращают несколько строк.
- В `get_club_full_report` суммы считаются отдельными подзапросами. Два `JOIN` на одного участника дали бы дублирование строк и завышенные суммы.

## Статус
Схема таблиц в папке не включена, функции нельзя запустить с нуля. Столбцы, которые используют функции, перечислены в начале `functions.sql`.
