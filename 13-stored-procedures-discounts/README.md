# 13. Процедуры с бизнес-логикой

**Тема:** процедуры с расчётом скидок, наценок, уценок и НДС, работа с датами (`EXTRACT DOW/DAY/MONTH`), агрегация внутри процедуры.
**Данные:** магазин продуктов (`magazin`): категории, товары, продажи.

## Задание
Задача «Магазин продуктов» из пяти пунктов:
1. Стоимость проданных единиц товара с учётом праздничной скидки.
2. Суммарная скидка по каждой из трёх категорий (10%, 15%, 20%) за день.
3. В первый понедельник месяца самый ходовой товар дорожает на 6%, самый неходовой — на 12%.
4. Во вторую пятницу месяца весь товар уценивается на 8%.
5. Квартальный отчёт: сумма продаж и НДС к уплате (категория 1 — 10%, категория 2 — 18%).

## Файлы
- `magazin_schema.sql` — база `magazin`: таблицы `categories`, `products`, `sales`, заполнение данными.
- `procedures.sql` — пункты 1–2: `calculate_discounts(id, date)` и `calculate_discount_summary(date)`.
- `procedures_points_3_4_5.sql` — пункты 3–5: `third(date)`, `fourth(date)`, `fifth(date)`.

## Что в решении
- Ветвление через `IF / ELSIF / ELSE`.
- Работа с датами: `EXTRACT(DOW ...)` для дня недели, `EXTRACT(DAY ...)` для номера дня в месяце (первый понедельник, вторая пятница), `EXTRACT(MONTH ...)` для кварталов.
- `COALESCE` для защиты от `NULL`, если продаж не было.
- Агрегация с `JOIN` и `GROUP BY` внутри процедуры.
- Популярность товара в пункте 3 считается по всей истории продаж.
