# 07. JOIN и UNION на базе интернет-магазина

**Тема:** соединение таблиц через связующие таблицы, `LEFT`, `FULL JOIN`, `UNION`, агрегаты.
**Данные:** интернет-магазин (категории, товары, клиенты, продажи, статусы).

Это отдельная работа, не связанная с папкой 06: другая база и другой набор задач.

## Задание
Семь задач на базе интернет-магазина. Нужно соединить таблицы, в том числе через связи «многие ко многим», сохранить строки без связей и объединить два разных условия отбора.

## Файлы
- `store_schema.sql` — полная схема БД с индексами и внешними ключами, заполнение данными.
- `queries_store_tasks_1_7.sql` — решения задач 1–7.

## Что в решении
- `INNER JOIN` через связующую таблицу `category_has_good`.
- `LEFT JOIN` для сохранения товаров без категории.
- `FULL JOIN` для полного соответствия в обе стороны.
- `UNION` для объединения двух условий отбора.
- Агрегаты `COUNT` и `SUM` поверх многотабличных `JOIN`.
