# 08. Материализованные представления и Python

**Тема:** `CREATE MATERIALIZED VIEW`, `REFRESH MATERIALIZED VIEW`, обёртка на Python (`psycopg2` и `.env`).
**Данные:** доставка (доставщики, доставки, товары в доставках).

## Задание
Создать три таблицы и заполнить их. Создать четыре материализованных представления: выборка по телефону, доставщики без доставок, заработок по тарифу, и объединение записей без связей. Вывести каждое представление и обновить одно из них.

## Файлы
- `db_schema.sql` — создание и заполнение таблиц для ручного запуска в psql или pgAdmin.
- `materialized_views.sql` — четыре представления для ручного запуска.
- `ModulDB.py` — класс `SqlQw` с методами создания таблиц, заполнения, создания представлений, вывода и обновления.
- `app_main.py` — главный файл, вызывает методы в порядке задания.
- `.env.example` — шаблон переменных окружения без реальных данных.

## Что в решении
- Класс `SqlQw` подключается к БД через переменные окружения из `.env`.
- Метод `show_view(view_name)` выводит результат любого представления по имени.
- Метод `refresh_view(view_name)` обновляет представление по имени.
- `app_main.py` выполняет полный порядок: создание таблиц, заполнение, создание четырёх представлений, вывод, обновление.

## Запуск
1. Скопировать `.env.example` в `.env` и заполнить свои данные.
2. Установить зависимости: `pip install psycopg2-binary python-dotenv`.
3. Запустить `python app_main.py`.

Файл `.env` в репозиторий не загружается (добавлен в `.gitignore`).
